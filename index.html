Modo prototipo

Carga datos inventados para probar el resumen mensual, los pagos fijos y el flujo de efectivo sin tocar Google Sheets.
Configuración
El Google Sheet ya está fijado en el código y el Apps Script también valida contra ese Sheet. Solo necesitas configurar el URL del Apps Script y el token privado.
Instrucciones

Paso 1 — Google Sheet

El Sheet familiar ya está configurado en el código y en Apps Script. No pegues IDs desde el navegador.


Paso 2 — Apps Script

En el Sheet: Extensiones → Apps Script → pega el código → Implementar como Web App.


Paso 3 — Make

Telegram Bot → Text Parser → Google Sheets. Ya está configurado y funcionando.


Paso 4 — Vercel

Sube esta carpeta a GitHub y conéctala a Vercel para tener la app en tu celular.
